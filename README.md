# Schrodinger-s-Cat-Burglar-AutoSplitter
An autosplitter for livesplit that works for the game "Schrodinger's Cat Burglar"
Currently only works for Steam and doesn't have a splitting feature. Currently just starts, resets, and shows game time.

To get it to work, open livesplit, right click it and select "Edit Layout..." click the plus and then "Control", "Scriptable Auto Splitter" to add the scriptable asl section. Double click it and then click "Browse..." next to "Script Path". Search for all files (dropdown on the right), then select the autosplitter. As long as you click "Save Layout" that should be it and you won't have to do anything until the autosplitter gets updated.
